# Task List
HTML • CSS • JavaScript — Simple Monthly Task Manager  
Live Demo: https://lavinia-81.github.io/Task-list/

A clean and responsive task management application built using vanilla JavaScript, HTML, and CSS.
This project represents one of my early steps into front‑end development, where I learned how to manipulate the DOM, handle user interactions, and update UI elements dynamically.

---

## Overview
Task List allows users to add, view, and remove tasks in a simple, intuitive interface.

It demonstrates foundational front‑end concepts such as:
- event listeners
- dynamic DOM updates
- responsive layout
- input validation
- basic state management in JavaScript

Even though it is a beginner project, it remains an important milestone in my learning journey.

---

## Features
### Core Functionality

## How to Use
- Open index.html in your browser.
- Type a task into the input field.
- Click Add Task.
- Your task will appear in the list below.
- Remove tasks by clicking the delete button next to each item.
